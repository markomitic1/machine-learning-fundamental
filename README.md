# Machine Learning Fundamentals — Python

A collection of machine learning exercises developed during my Artificial Intelligence coursework and individual practice at the Faculty of Organizational Sciences, University of Belgrade.

The notebooks demonstrate hands-on experience with Python, data preprocessing, exploratory data analysis, machine learning algorithms, data visualization, and result interpretation.

## Notebooks

### Linear Regression — Fast Food Nutritional Analysis
`linear-regression/fast-food-linear-regression.ipynb`

Analysis of nutritional data from fast-food restaurants using
linear regression, including data preprocessing, exploratory
analysis, feature selection, statistical modeling, diagnostic
visualizations, and model evaluation.



### Decision Tree — Bank Customer Classification
`decision-tree/bank-decision-tree.ipynb`

Classification of bank customers using a Decision Tree algorithm, including data preparation, model training, hyperparameter tuning, and performance evaluation.

### K-Means — Spotify Song Clustering
`k-means/spotify-kmeans-clustering.ipynb`

Exploratory analysis and clustering of Spotify songs based on their musical characteristics, including feature scaling, cluster selection, visualization, and interpretation.

## Technologies

- **Python**
- **pandas, NumPy**

- **scikit-learn**

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Open the notebooks in Jupyter Notebook or PyCharm.
4. Ensure the corresponding CSV datasets are in the same directory as the notebooks.
5. Run the cells in order.
